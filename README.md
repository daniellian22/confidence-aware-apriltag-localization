# AprilTag Localization Under Viewpoint Variation

This repository contains code, analysis scripts, plots, and report material for an AprilTag-based localization project focused on camera calibration, coordinate-frame transformations, viewpoint robustness, and multi-tag fusion.

## Main components

- Camera calibration with OpenCV checkerboard images
- AprilTag detection and pose estimation
- Coordinate transforms into a shared origin frame
- Static-view and movement evaluation scripts
- Plot generation for report and presentation figures

## Key files

- `calibrate_camera.py`
- `analyze_static_tags.py`
- `extract_scan_points.py`
- `merge_scan_with_cmd.py`
- `plot_scan_results.py`
- `make_project_plots.py`
- `report.txt`
