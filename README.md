# AprilTag Localization Under Viewpoint Variation

This repository contains code, analysis scripts, plots, and report material for an AprilTag-based localization project focused on camera calibration, coordinate-frame transformations, viewpoint robustness, and multi-tag fusion.

## Main Components

- Camera calibration with OpenCV checkerboard images
- AprilTag detection and pose estimation
- Coordinate transforms into a shared origin frame
- Static-view and movement evaluation scripts
- Plot generation for report and presentation figures

## Key Files

- `calibrate_camera.py`
- `analyze_static_tags.py`
- `extract_scan_points.py`
- `merge_scan_with_cmd.py`
- `plot_scan_results.py`
- `make_project_plots.py`
- `report.txt`

## Output Figures

Presentation-ready figures are available in `final_plots/` and at the repository root.

## How To Run

### Current Snapshot (docs only)

This repository snapshot currently contains documentation files only:

- `README.md`
- `report.txt`

You can view the report directly in any text editor.

### Full Project Mode (when code files are present)

If you restore the full project scripts and data, use this flow:

```bash
# 1) Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 2) Install dependencies
pip install numpy pandas matplotlib opencv-python scipy pupil-apriltags

# 3) Run final plot generation (if script exists)
python make_project_plots.py

# 4) Run scan analysis (if script exists)
python plot_scan_results.py --csv scan_points_with_grid.csv --out scan_analysis.png
```

Expected outputs include PNG figures in the repository root and/or `final_plots/`.
